    How it chooses

    Each suggestion is scored by how sure detection is, what you picked for this kind of data before, and how recently. Pick an alternative and copy it a few times: it moves to the front and gets a green dot.

    Exact, then smart

    • Every result comes from Bitlathe's deterministic tools: the same output every time, in milliseconds.
    • AI only steps in when you type words instead of data. It plans which tools to run; the tools still compute.
    • Anything that looks secret (tokens, keys, passwords) is marked and never sent to a model.
    • The full tool screens stay one click away for heavy work: diff, regex, CSV tables.

    Same tools for agents (MCP)

    The bl CLI would serve Bitlathe's tools over the Model Context Protocol, so Claude Code and other agents get exact results instead of guessing.
